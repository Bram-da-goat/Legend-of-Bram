# The Legend of Bram — Blender to Unreal

This single folder contains the editable `.blend`, rebuild script, preview, and Unreal-ready FBX exports for the realistic remake.

## Scale and naming

- Blender units are meters; Unreal imports the FBX files at centimeter scale.
- Static meshes use Unreal's `SM_` prefix.
- Materials use the `M_` prefix.
- Weapon origins are placed at the bottom of each grip for easy socket attachment.
- Forward is `-Y` and up is `Z` during FBX export.

## Generated weapon pack

- `SM_Bram_Hammer.fbx`
- `SM_Bram_WoodcutterAxe.fbx`
- `SM_Bram_OrcWarClub.fbx`

The editable source is `LegendOfBram_WeaponPack.blend`, and the rendered look-development image is `Bram_WeaponPack_Preview.png` in this same folder.

The Woodcutter Axe is an original, conventional felling-axe model generated by the build script. It has a gently curved hickory handle, broad forged wedge head, convex polished edge, flat poll, and wrapped lower grip.

## Rebuild

Run Blender in the background from the repository root:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python 'Blender\build_weapon_pack.py'
```
